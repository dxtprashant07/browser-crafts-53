# Backlink Strategy — Subtrate

Angle to lean on: **free, no-signup, 100% client-side (nothing uploaded)**. That's
the differentiator vs Smallpdf/TinyPNG/iLovePDF, and it's what gets links —
privacy-conscious sites, dev tool roundups, and "no upload" listicles actively
seek this out.

## 1. Directory / listicle submissions (fastest, lowest effort)

Submit each relevant tool (not just homepage) to:
- Free tool directories: AlternativeTo, Product Hunt, SaaSHub, ToolFinder,
  FreeTools, Slant
- Dev-tool directories: dev.to tool lists, GitHub "awesome-*" lists
  (`awesome-pdf-tools`, `awesome-developer-tools`) via PR
- Privacy-tool directories: PrivacyTools.io-style lists, "runs in browser"
  roundups

Submit the specific tool page URL (e.g. `/tools/pdf/merge-pdf`), not just `/`
— matches searcher intent and spreads link equity across pages instead of
stacking it all on the homepage.

## 2. Build-in-public / dev community links

- Post launches on r/webdev, r/SideProject, r/privacy, Hacker News "Show HN"
  — one tool or the whole platform, framed as "built this because X paid
  tool uploads your files"
- Answer Stack Overflow / Reddit questions where a free client-side tool is
  the actual answer (e.g. "how do I convert HEIC to JPG without uploading")
  and link the specific tool page, not the homepage

## 3. Comparison content (earns links naturally)

Add a couple of `/vs` or comparison-style landing pages (e.g. "Subtrate vs
TinyPNG", "browser-based vs upload-based image compression") — this is
exactly the kind of page other sites cite when writing "best free tools"
roundups, and it's cheap to build on the existing tool-page pattern.

## 4. Digital PR angle

The "your files never leave your browser" claim is a genuine story hook for
security/privacy journalists writing about the risk of uploading PDFs/photos
to random web tools. A short pitch to privacy-focused newsletters/blogs
(e.g. Restore Privacy, Techlore) citing this as the reason the tool exists
can land higher-authority links than directory submissions.

## What NOT to do

- No paid link farms / PBNs — Google + AI engines both penalize this, and per
  the GEO audit, backlink volume is a weak AI-citation signal anyway
  (correlation ~0.27) vs brand mentions on Reddit/YouTube/Wikipedia
  (~0.7+). Spend effort on #2 and #4 above before chasing raw link count.

## Execution note

This doc is a plan, not automatable from this repo — submissions, Reddit
posts, and journalist pitches are manual/off-site actions for you to run.
